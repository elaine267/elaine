# Fonte normativa selecionada
## Identificação
Clt, art. 477.
## Trecho conferido
[O artigo 477, parágrafos 6º e 8º, da CLT, determina que o pagamento das verbas rescisórias deve ocorrer em até 10 dias corridos, sob pena de multa equivalente a um salário do empregado por atraso..]
## Uso no projeto
Conferir qual periodo foi demitida,
comprovar pagamento.
